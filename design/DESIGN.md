# 设计规格：彩虹桥

所有者已于 2026-10-29 定稿。视觉参考是同目录的 `mockup.html`，直接用浏览器打开，顶部可以切换五个页面状态。像素、颜色、动效以 mockup 为准；本文写的是 mockup 表达不了的规则。mockup 从 Google Fonts 加载字体，只用于预览，正式站点不能这样做。

不在本规格里的东西不要加。比如“关于”页：所有者还没有提供文字，导航里先不放。

## 1. 页面与范围

| 页面 | 地址 | 模板 |
|---|---|---|
| 首页 | `/` | `list.html`（首页变体） |
| 分类页 | `/life/`、`/tech/` | `list.html`（分类变体） |
| 文章页 | `/posts/<slug>/` | `post.html` |

每个列表页都要处理“没有文章”的空状态，这也是博客现在的真实状态。

## 2. 设计令牌（写在 `site.css` 的 `:root`）

站点只有一套深色外观，不做浅色或主题切换。

```
--ground:  #3B4240   页面底色（灰绿）
--ground2: #353B39   卡片悬停、代码块底色
--ink:     #EEF0EC   标题、主要文字
--body:    #DFE3DF   文章正文
--dim:     #9AA29E   次要文字
--faint:   #6E7773   日期、标签、页脚
--rule:    rgba(238,240,236,.09)  背景网格线
--dash:    rgba(238,240,236,.16)  虚线边框

彩虹六色，从“生活”端到“技术”端：
--r6 #FF7A7A  --r5 #F0559C  --r4 #CF4FC4  --r3 #A457E6  --r2 #7B63F2  --r1 #5F7CFF
生活 = r6/r5/r4（暖），技术 = r3/r2/r1（冷）

--ease: cubic-bezier(.23, 1, .32, 1)   全站唯一的缓动曲线
```

彩虹色只用在五个地方：彩虹、站标、分类小标记、文章阅读进度条、文章卡片缩略图。不要用在按钮、正文链接或大面积背景上。

## 3. 字体

| 用途 | 字体 | 字重 |
|---|---|---|
| 标题（首屏问候、卡片标题、文章标题、正文二级标题、上一篇/下一篇） | 思源宋体 Noto Serif SC | 500、600 |
| 正文和界面文字 | 思源黑体 Noto Sans SC | 300、400、500 |
| 英文和数字信息（日期、阅读时长、标签、站名、代码） | IBM Plex Mono | 400、500 |

- 三套字体都是 SIL OFL 开源授权。字体文件放进 `assets/fonts/`，同目录放 `OFL.txt`。
- 中文字体必须子集化：收录全部文章、模板、`site.json` 实际用到的字，再加上一份常用字表（GB2312 一级字 3500 个）。新文章的字通常已经在常用字表里，所以不用每次都重跑。
- 子集化脚本单独放在 `scripts/fonts.py`，依赖 `fonttools` 和 `brotli`，只在作者需要更新字体时手动运行。`build.py` 和 `check.py` 必须继续只用 Python 标准库。
- `check.py` 新增一项检查：如果文章里出现子集没收录的汉字，就打印警告，提示运行 `scripts/fonts.py`。只警告，不让检查失败。
- 输出 woff2 格式，`font-display: swap`。首页预加载黑体 400 和宋体 600。体积目标：每个中文字重不超过 500KB。
- 将来所有者可能会换中文字体，所以字体名只写在 `:root` 的 `--serif`、`--sans`、`--mono` 三个变量里，组件样式里不要直接写字体名。

## 4. 组件

**顶栏**：左边是站标（两道虚线小拱 + `sulik0`，等宽字体）；右边是导航“首页、生活、技术”。当前页有一个半透明高亮块，鼠标悬停时高亮块滑到对应项，移开后滑回当前页（JS）。

**背景网格**：88px 见方的细线网格，只铺在首屏，往下渐隐（`mask-image`）。

**首屏**：左右两栏。
- 左栏依次是：问候“你好，**sulik0**”（宋体，sulik0 加粗）、等宽副标题“生活感悟 / 技术学习”、简介、链接。
- 简介和链接从 `site.json` 新增的 `intro`（字符串）和 `links`（`[{label, url}]`）读取。默认都为空，为空时不输出对应的元素。**不得编写任何个人信息。**
- 右栏是彩虹桥，见第 5 节。
- 分类页首屏：左栏是分类名和篇数，右栏是缩小的彩虹（最大宽度 300px），只亮本分类那一半。

**分隔胶囊**：“我写的文章 ↓”，两侧是虚线。箭头每 1.8 秒轻轻下沉一次，“减少动态效果”时停止。只在首页显示。

**分类筛选**（首页）：`分类：全部 n、生活 n、技术 n`，数字由 `build.py` 统计。点击后在本页筛选卡片（JS）。没有 JS 时，这三项是指向 `/`、`/life/`、`/tech/` 的普通链接。

**文章卡片**：
- 虚线边框，圆角 12px。左边依次是等宽 meta（分类 · 日期 · 阅读时长）、宋体标题、摘要；右边是 112px 宽的缩略图：分类色的三道同心弧，生活用暖色，技术用冷色。
- 悬停时边框变实线、底色变成 `--ground2`、标题后的箭头滑入、缩略图里的弧上移 6px。按下时缩到 0.985。
- 阅读时长 = 正文汉字数 ÷ 400，向上取整，单位“min”。

**空状态**：虚线框，居中写“还没有文章”和“第一篇会出现在这里。”。分类页写“这个分类还没有文章”。

**页脚**：虚线上边框，左边 `© 年份 sulik0`，右边“静态生成 · 无追踪”，都用等宽字体。

## 5. 彩虹桥（核心组件）

**几何**（SVG，viewBox `0 0 360 250`，圆心 `(180, 222)`）：
- 共 6 圈，第 i 圈（i = 0…5）的半径 r = 170 − 18i，分成 n = round(r / 7.2) 段。
- 第 k 段（k = 0…n）起点的角度为 π + (k/n)·π；每一笔的长度是一个分段角的 0.55 倍。超出底线的那一笔丢弃。
- 线宽 7，圆头。
- 颜色按左右位置取 `t = k/n`，`floor(t·6)` 依次对应 r6 → r1：最左边是 r6 暖红，最右边是 r1 冷蓝。
- 拱内居中两行字：等宽小字（如“生活 3 · 技术 3”）和一句提示（如“选一头走进去”）。拱脚下方分别标“生活”和“技术”。

**由 `build.py` 生成**：SVG 直接写进 HTML，没有 JS 也能完整显示。左右两半各包在一个 `<a>` 里，分别指向 `/life/` 和 `/tech/`。

**交互（JS）**：
- 入场：每一笔从 0.2 倍缩放淡入，延迟为 `350 + t·700 + 圈序·40` 毫秒，形成从左往右亮起的效果。
- 靠近：鼠标 36px 范围内的笔沿半径方向外推，最多 7px，放大到 1.18 倍，变亮 25%。
- 悬停一侧（首页）：另一半透明度降到 0.2，对应拱脚文字变亮，拱内文字改成“生活 · n 篇 / 点击，只看这一类”，下方卡片实时筛选。鼠标移开后恢复。
- 点击一侧（首页）：锁定筛选，平滑滚动到文章区，不跳转页面。
- 分类页：本分类那一半常亮，另一半常暗；点击暗的那一半，跳转到另一个分类页。
- 触屏设备没有悬停：点击彩虹的一半直接跳转到对应分类页。
- 没有文章时：全部笔画变成 `rgba(238,240,236,.14)` 的灰色，拱内写“还没有文章 / 写下第一篇，桥就有了颜色”，不响应悬停和点击。

## 6. 文章页

- 顶部 2px 阅读进度条，颜色是本分类的三色渐变，随滚动变长（JS）。没有 JS 时不显示。
- 返回链接：一个小半拱图标加分类名，指向分类页。
- 标题：宋体 500，字号 `clamp(28px, 4.4vw, 40px)`。
- meta 行：分类（生活用 r5，技术用 r1）· 日期 · 阅读时长 · 约 n 字。下方一条虚线。
- 正文：黑体 300，15.5px，行高 2，颜色 `--body`，最大宽度 680px。
  - 二级标题：宋体 600，前面带一个等宽的淡色 `#`。
  - 引用：左侧 1px 虚线竖线，文字颜色 `--dim`。
  - 代码块：虚线边框，圆角 10px，底色 `--ground2`，等宽 13px。**不做语法高亮**（避免引入依赖）。
  - 行内代码：半透明底色，圆角 4px。
  - 链接：浅色文字，带 1px 下划线，悬停时下划线变亮。
- 文末：上一篇和下一篇两张虚线卡片。没有上一篇或下一篇时省略对应那张。

## 7. 动效

| 动效 | 规则 |
|---|---|
| 入场 | 带 `rise` 的元素从 `translateY(8px)`、`blur(4px)`、透明度 0 过渡到原位，600ms，每个元素比上一个晚 60ms |
| 链接下划线 | 悬停时从左往右划出，移开时从左往右收回，320ms |
| 按下 | 按钮缩到 0.95–0.96，卡片缩到 0.985，140–160ms |
| 颜色和边框 | 200–240ms |

- 全部使用 `--ease`。不要有持续循环的动画，唯一的例外是分隔胶囊里的箭头。
- `prefers-reduced-motion: reduce` 时关闭所有位移、模糊和延迟，内容直接显示。
- 入场动画必须由 JS 在加载后添加 `.go` 类来触发。没有 JS 时，`.rise` 元素必须直接可见。可以用 `<html class="js">` 来控制。

## 8. 手机（宽度 ≤ 760px）

- 页面左右边距 20px，顶栏可以折行。
- 首屏变成单栏，彩虹移到问候语上方，宽度 80%，居中。
- 卡片单栏显示，隐藏缩略图。
- 上一篇和下一篇上下排列。
- 检查 390px 宽度：页面不能横向滚动。

## 9. 技术约束（沿用 AGENTS.md）

- 继续保持静态站点、Python 标准库生成、不引入任何第三方前端库。
- JS 只能是 `assets/site.js` 一个文件，自己写，不压缩也小于 6KB，`defer` 加载。
- 不要提交示例文章。验证有文章的状态时，在本地临时添加测试文章，验证完删除。
- `README.md` 按 AGENTS.md 的要求补充：新增的字体脚本怎么用、验证步骤、怎么回退。

## 10. 验收清单（设计方逐项检查）

1. `python3 scripts/build.py && python3 scripts/check.py` 通过，空状态和有文章两种情况都要通过。
2. 首页、分类页、文章页、空状态和 mockup 对照，没有明显差异。
3. 彩虹的几何、颜色顺序和第 5 节一致；悬停、点击、分类页、触屏、空状态五种行为都正确。
4. 关闭 JS 后：页面完整可读，彩虹两半和分类筛选都是可用的链接。
5. 开启“减少动态效果”后没有位移和模糊。
6. 390px 宽度下没有横向滚动。
7. 字体从 `assets/fonts/` 本地加载，没有任何外部请求；每个中文字重不超过 500KB；`OFL.txt` 存在。
8. 控制台没有报错。
9. `site.json` 的 `intro` 和 `links` 为空时，首屏不出现空元素，也没有占位文字。
